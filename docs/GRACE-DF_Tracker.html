The five claims. C1 evidence drift exists — the label survives degradation, the explanation doesn't · C2 frequency tokens plus degradation-invariant training fix it · C3 grounding is cheap — a sub-1B model matches a 24B agent ensemble · C4 calibrated abstention converts robustness into utility · C5 the explanation is causally verifiable — restore the predicted region and the verdict flips, restore a random one and it doesn't.
